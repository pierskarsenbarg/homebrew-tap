# homebrew-tap

Personal Homebrew tap for [pierskarsenbarg](https://github.com/pierskarsenbarg)'s tools.

## Usage

```bash
brew tap pierskarsenbarg/tap
brew install pierskarsenbarg/tap/pulumi-package-docs
```

## Formulas

- [`pulumi-package-docs`](Formula/pulumi-package-docs.rb) — [pierskarsenbarg/pulumi-package-docs](https://github.com/pierskarsenbarg/pulumi-package-docs), a local documentation viewer for the parameterized/local Pulumi providers used by a Pulumi project. Published automatically by that repo's release workflow.
